# Git Workshop Agenda

1. Show the agenda

2. Introduction to the lingo
    - What is git?
    - Why use git?
    - What is version control?
    - What is a repository?
    - What is a commit?

3. Practical part - Intro - will use the command line  - use [this](https://github.com/kuahyeow/git-workshop) syllabus
The goal of this part is to understand the basic mechanics of git and it's commands working in local environment.
   - Start a simple project 
   - Initialize a git repository in the project
   - Stage changes
   - Create a commit
   - See commit history
   - Revert a commit
   - Create a branch
   - Merge a branch
   - Resolve a merge conflict

4. Practical part - Advanced - To use with an IDE/text editor
The goal of this part is to understand the collaboration capabilities that git enables.
   - Pull a project
   - Work in groups of 2-3 people
   - Each create a branch
   - Each makes some changes - implements a functionality
   - Push to remote
   - Pull Request
   - Code review
   - Merge
   - Merge conflicts
   - .gitignore

1. Q&A

2. Recap

3. Self learning recommendations
   - Stash changes
   - Cherry-pick a commit
   - Rebase a branch
   - Tag a commit
   - Squash commits
   - Git hooks
   - Different branching strategies
