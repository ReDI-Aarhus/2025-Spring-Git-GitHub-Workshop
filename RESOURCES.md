# Git Learning Resources

A collection of useful resources to help you go beyond the workshop and strengthen your Git skills.

---

## Getting Started with Git

- [Pro Git (free eBook by Scott Chacon & Ben Straub)](https://git-scm.com/book/en/v2) — The definitive Git reference
- [Official Git Documentation](https://git-scm.com/doc)
- [GitHub Git Handbook](https://docs.github.com/en/get-started/using-git/about-git)
- [Atlassian Git Tutorials](https://www.atlassian.com/git/tutorials)

---

## Day 1 Deep Dives

Resources to reinforce local Git fundamentals covered on Day 1.

- [Pro Git Ch. 2 — Git Basics](https://git-scm.com/book/en/v2/Git-Basics-Getting-a-Git-Repository) — Relevant to: staging, committing, history
- [Pro Git Ch. 3 — Git Branching](https://git-scm.com/book/en/v2/Git-Branching-Branches-in-a-Nutshell) — Relevant to: Day 1 branching & merging
- [Atlassian — Undoing Changes](https://www.atlassian.com/git/tutorials/undoing-changes) — Relevant to: revert, reset, checkout

---

## Day 2 Deep Dives

Resources to reinforce collaboration and advanced topics covered on Day 2.

- [Pro Git Ch. 5 — Distributed Workflows](https://git-scm.com/book/en/v2/Distributed-Git-Distributed-Workflows) — Relevant to: remotes, collaboration
- [GitHub — About Pull Requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests) — Relevant to: Day 2 PR workflow
- [Atlassian — Git Stash](https://www.atlassian.com/git/tutorials/saving-changes/git-stash) — Relevant to: Day 2 stash exercise
- [Pro Git Ch. 7.6 — Rewriting History](https://git-scm.com/book/en/v2/Git-Tools-Rewriting-History) — Relevant to: interactive rebase, squashing

*Tip:* The best way to learn Git is by **using it daily**:
- Keep a personal project under version control.
- Practice branching and merging.
- Experiment with commands in a test repo.
