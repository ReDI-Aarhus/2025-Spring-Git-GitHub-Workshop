# April 2025 Git Workshop

This repository contains all the material for the Git Workshop conducted in April 2025 for ReDI School of Digital Integration in Aarhus.   
For the first practical part, follow the [syllabus](https://github.com/kuahyeow/git-workshop).  
For the second practical part follow the teacher's notes in the `Agenda.md` file and use the `index.html`, `scipt.js` and `style.css` files.

Author: Adam Petro, heavily inspired by https://github.com/kuahyeow/git-workshop.
