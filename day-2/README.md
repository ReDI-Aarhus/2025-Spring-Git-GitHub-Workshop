# Day 2: Collaboration & Advanced Git

Welcome to Day 2! Today we move beyond your local machine — you'll resolve conflicts, collaborate on GitHub, and learn power-user techniques.

---

## Learning Objectives

By the end of today you will be able to:

- Confidently resolve merge conflicts.
- Use remotes, push, pull, and collaborate through pull requests.
- Use `stash` to save work-in-progress without committing.
- Recover "lost" commits with `reflog`.
- Apply selective commits with `cherry-pick`.
- Rewrite history cleanly with interactive rebase.
